# 🎬 AI YouTube Shorts Generator — Web GUI

Браузерный GUI готов к использованию.

## Что установлено

✅ Flask веб-сервер  
✅ HTML/CSS/JavaScript интерфейс (на русском)  
✅ Реал-тайм прогресс через Server-Sent Events  
✅ Оба режима (API и Local)  
✅ Видео-превью и скачивание  
✅ Очередь задач (queued → running → done/error)  
✅ Ревью-панель: превью, удаление, обрезка, «💾 Сохранить» (рефрейм + эффекты, перенос в `output/saved/`)

## Быстрый старт

### Windows
```bash
start_gui.bat
```

### Linux/Mac
```bash
./start_gui.sh
```

Или вручную:
```bash
venv/Scripts/python.exe app.py   # Windows
venv/bin/python app.py           # Linux/Mac
```

Потом открой в браузере: **http://localhost:5000**

## Возможности интерфейса

### Настройки
- YouTube URL или локальный файл
- Режим (API через MuAPI или Local)
- Количество клипов (1-10)
- Aspect ratio (9:16, 1:1, 16:9)
- Качество исходного видео (360p-1080p)
- Язык распознавания (опционально)

### Водяной знак (оверлей)
- Чекбокс «Показывать водяной знак» (env `OVERLAY_ENABLED`, по умолчанию вкл)
- **Drag-canvas 180×320** — таскаешь точку мышкой, позиция сохраняется как `overlay_x`/`overlay_y` (0..1, центр оверлея). Заменяет 9-сетку; значения клампятся в кадр.
- Выбор позиции сеткой + отступ + масштаб как раньше.

### Обработка (применяется по кнопке «💾 Сохранить» в ревью)
Эффекты **не применяются на этапе генерации** — сначала делаются горизонтальные черновики 16:9, чтобы не грузить комп на отбракованных шортсах. После просмотра выбираешь нужные и жмёшь «Сохранить»: клип рефреймится в вертикаль и получает эффекты.
- **Вырезать паузы** (`SILENCE_CUT`, по умолчанию вкл) — jump-cut тишины на черновике, ты сразу видишь итоговый тайминг. Порог: `SILENCE_NOISE_DB` (дБ), `SILENCE_MIN_DUR` (с), `SILENCE_KEEP_EXTRA` (с).
- **Размытые полосы 9:16** (`BLUR_BARS`, по умолчанию вкл, только 9:16) — фон 1080×1920 из размытого видео, ролик по центру 1080×1344, полосы сверху/снизу по 288px.
- **Фоновая музыка** (`MUSIC_ENABLED`+`MUSIC_FILE`+`MUSIC_VOLUME`) — загрузка трека, громкость 0-100%, подмешивается amix-ом после одобрения.
- **Субтитры** (`CAPTIONS_ENABLED`, по умолчанию ВЫКЛ) — вжигаемые субтитры из word-timestamps faster-whisper. Стиль: «Караоке (подсветка слова)» (`CAPTION_STYLE=karaoke`, текущее слово подсвечивается золотом) или «Классические» (`classic`). Сайдкар `<клип>.mp4.ass` пишется рядом с черновиком; вжигание — при финализации, после размытых полос, до оверлея/музыки. Тонкие настройки: `CAPTION_FONT`/`CAPTION_FONT_SIZE`/`CAPTION_MAX_WORDS`/`CAPTION_MARGIN_V`/`CAPTION_TEXT_COLOR`/`CAPTION_ACTIVE_COLOR` и др. (hex RRGGBB). Важно: word-timestamps берутся только при свежей транскрибации — если у видео старый кэш `.srt` без слов, удали `<output>/<имя>.srt` и перегенерируй.
- **Трекинг лица** (`FACE_TRACK_ENABLED`, по умолчанию вкл) — OpenCV Haar-детектор следит за лицом при вертикальном кропе. Выкл = статичный центр-кроп ffmpeg-ом (быстрее, не «гуляет» кадр).

### Процесс генерации
- Очередь задач: «Добавить в очередь», статусы queued/running/done
- Реал-тайм прогресс-бар по этапам:
  - Downloading → Transcribing → Analyzing → Rendering
- Текущий статус и этап

### Результаты (ревью-панель)
Для каждого шортса:
- **Viral Score** (0-100), **Title**, **Hook Sentence**, **Virality Reason**
- **Видео-превью**, **размер** и **длительность**
- **Превью**, **💾 Сохранить** (рефрейм в целевой aspect + эффекты, перенос в `output/saved/`, бейдж «Сохранено»), **Обрезать** (по `-ss/-to`, пишет `<name>_trimmed[_N].mp4`), **Удалить** — удаляет файл и карточку
- **«🖼 Обложка»** → кадр-обложка JPEG (по умолчанию с 12% длительности, кладётся рядом с клипом как `<name>_thumb[_N].jpg`, заголовок — имя файла; env: `THUMB_AT_PERCENT`, `THUMB_TITLE`)

## API Endpoints

- `GET /` — главная страница
- `POST /api/generate` — постановка задачи в очередь, возвращает `202 {job_id, position}`
- `GET /api/jobs` — список задач (очередь + статусы)
- `GET /api/jobs/<job_id>/shorts` — шортсы задачи (name, url, size_bytes, duration_sec, finalized, saved)
- `GET /api/status/<job_id>` — статус задачи
- `GET /api/progress/<job_id>` — SSE-стрим прогресса
- `POST /api/shorts/delete` — удалить шортс `{url}`
- `POST /api/shorts/trim` — обрезать `{url, start_offset, end_offset}`
- `POST /api/shorts/save` — одобрить черновик `{url, aspect_ratio?}`: рефрейм в целевой aspect + эффекты (настройки запомненной задачи), перенос в `output/saved/<подпапка>/`, черновик удаляется; уже сохранённый → `400`
- `POST /api/shorts/finalize` — применить эффекты к черновику `{url, aspect_ratio?}` (in-place, бэкап `*.draft.mp4`)
- `POST /api/upload` — загрузить локальный ролик
- `POST /api/upload/music` — загрузить трек для фоновой музыки
- `GET /output/<путь>` — раздача локальных видео (с confinement внутри output dir)

## Разница режимов

### API Mode
- Быстрая обработка через MuAPI
- Нужен `MUAPI_API_KEY`
- Результаты как hosted URLs
- Встроенный видео-плеер

### Local Mode
- Полностью оффлайн (кроме LLM)
- Нужен `OPENAI_API_KEY` или `GEMINI_API_KEY`
- Видео лежат в `output/<название ролика>/`
- Поддержка локальных файлов

## Двухэтапный рендер (draft → final)

1. **Генерация** делает горизонтальный черновик **16:9 без эффектов** (cut → вырезка пауз, без кропа). Паузы вырезаются сразу, чтобы ты видел итоговый тайминг, а исходный кадр целиком остаётся до ревью.
2. **Ты смотришь** превью в ревью-панели и отбраковываешь лишнее («Удалить» просто стирает файл).
3. **Одобренные** шортсы жмёшь «💾 Сохранить» — клип рефреймится в целевой aspect (9:16), на него накладываются blur-полосы, водяной знак `TIKTOK1.mov`, музыка (с настройками той задачи), и он переносится в `output/saved/<подпапка>/`. Черновик стирается, карточка получает бейдж «Сохранено» — повторное сохранение того же файла не перезаписывает.

Так слабый комп не тратит GPU на отброшенные ролики.

## Troubleshooting

### Порт уже занят
Смени порт через env: `set GUI_PORT=5001` (Windows) / `export GUI_PORT=5001` (Linux/Mac) перед запуском. Хост тоже через env — `GUI_HOST` (по умолчанию `0.0.0.0`, с предупреждением в консоль; поставь `127.0.0.1`, если панель нужна только с этого компа), а `GUI_TOKEN` включит токен-аут для `/api/*`.

### API ключи не настроены
Проверь `.env` (см. `.env.example`)

### Ошибка "Module not found"
Проверь, что Flask установлен:
```bash
venv/Scripts/python.exe -m pip install flask
```
